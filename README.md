## 国内访问：Vultr 怎么样，绕不开的一条线

Vultr 全部机房在海外，中国大陆一个节点都没有。它走普通国际线路，没有 CN2、AS9929 这类针对国内的优化路由。亚洲节点到国内的延迟大致在几十毫秒到一百多毫秒之间，晚高峰会抬升，偶尔丢包。不同来源测出来的东京延迟从 60ms 到 200ms 都有，差异来自测试时间、线路拥堵和运营商，任何一个单点数字都不能当保证。

IP 被封是另一个老问题。Vultr 允许删机重建免费换 IP，这功能本身方便，但架不住有人反复开机器刷 IP，结果 IP 池里积了大量被封地址。新开一台机器可能一上来就连不上，删了重建还是被封，得试几次才碰到能用的。这个问题 2021 年就有人反映，到 2026 年没见好转。

想验证自己的线路，最稳妥的做法是先按小时开一台东京或首尔机器，用实际业务在晚高峰跑一遍，看延迟和丢包。按小时计费，测几个小时成本很低。东京的带宽资源比首尔充足，延迟总体低 10–30ms；新加坡有时会绕路，物理距离近不代表线路直。S2 那边有用户拿 2 核 4G 的机器放了近 150 个网站，跑着不卡也没宕机，但这是别人的使用场景，你的流量结构和线路未必一样。

## 真实成本：$5/月不是全部

按小时计费的意思是开几小时扣几小时，删除实例立刻停止计费。关机但不销毁仍然计费，因为资源还占着。想停掉必须销毁实例，这一点很多人第一次用会踩。

流量是账单失控的主要来源。每个套餐含固定的月度传出流量，入站通常免费，超了按量收费。北美和欧洲大约 $0.01/GB，亚洲和澳洲可以到 $0.025–$0.05/GB 甚至更高。拿 $6/月这档算，一年基础费 $72；如果每月超 100GB，按亚洲价 $0.025/GB 就是每月多 $2.5，一年 $30；每月超 1TB 就是每月 $25，一年 $300，比机器本身贵几倍。这是估算口径，实际单价和计费方式以控制面板为准。

赠金的有效期差别很大。$300 那类体验金 30 天清零，充值匹配的赠金 12 个月，自己充的钱不限期。最低充值 $10 才能激活账户，支付宝、PayPal 这类非信用卡方式都按这个门槛。信用卡验证会先扣几美元预授权，一个月后退回。Vultr 不提供退款，付费模式是先用后付费，赠金扣完才动自己的余额。

## 按场景选套餐：多数人用不上 $48 以上

**纯 IPv6 实验**：$2.5 那档，1 核 0.5GB、10GB SSD、0.5TB 流量，没有 IPv4。拿来学 Linux、跑个临时脚本可以，建站不行，别人访问不到。

**个人博客、轻量站**：$5 档，1 核 1GB、25GB SSD、1TB 流量。跑 WordPress、静态站、小型应用够用。再低就没法跑数据库型网站了。

**同为 $6，High Frequency 和 High Performance 怎么选**：HF 给 32GB NVMe 和 1TB 流量，HP 给 25GB NVMe 和 2TB 流量。吃 CPU 单核性能选 HF，吃流量选 HP。存储差 7GB，流量差一倍，这个取舍比看名字有用。

**小型外贸站、多站点**：$12–$24 档。$12 是 1 核 2GB，$24 是 2 核 4GB，流量 2–4TB。站点数量多、有数据库查询的，从 $12 起比 $5 稳。

**数据库或 IO 密集**：才需要上 NVMe 的高档。官方宣传 High Performance 的 NVMe 读写能到 2000MB/s 以上，这是官方口径，实际以自己测为准。普通展示站用不出这个差距。

$48 以上是 4 核 8GB 或 3 核 8GB，跑中型应用、多站点集群才用得到。个人和小团队基本碰不到这条线。

## FAQ

**国内访问速度到底怎么样？**
亚洲节点到国内大致几十毫秒到一百多毫秒，晚高峰会抬升，偶发丢包。没有 CN2、AS9929 这类优化线路，电信用户体验更明显。想要国内稳定低延迟，得看专做优化线路的商家。

**按小时计费怎么算？**
开几小时扣几小时，删除实例停止计费。关机不销毁仍然计费。月付价格只是锚点，实际按小时累计。

**能退款吗？**
不提供退款。付费模式是先用后付费，赠金扣完才动余额。建议先充最低 $10，按小时开机器试，不合适就删。

**东京还是首尔？**
东京带宽资源更足，延迟总体比首尔低 10–30ms。国内用户两个都可以试，首尔对东北亚也有优势，最终按自己实测的晚高峰表现定。

**能装 Windows 吗？**
可以，但需要额外购买 Windows Server 授权，价格比 Linux 方案贵不少，一般不建议用它跑 Windows。

**快照收不收费？**
各来源说法冲突，有的说免费，有的说占存储并计费。控制面板实际显示为准。不管收不收费，都别把快照当唯一备份，它和机器在同一个数据中心。
